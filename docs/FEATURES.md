# 功能清单

初次整理：2026-09-12；公开发布复核：2026-10-02，应用源码未变更。
本文描述仓库中的实现，不把源码、单元测试或 HTTP 成功等同于实盘可用。
对应源码和测试入口见 [模块地图](MODULES.md)，当前阻塞见 [状态说明](STATUS.md)。

## 状态口径

- **已有实现**：有相应代码和测试，是否在某台机器上可用仍需运行验收。
- **条件可用**：依赖新鲜券商数据、来源权限、日历、账本或真实人类授权；缺失即降级。
- **研究 / 预览**：仅供观察解释，不构成生产评分、正期望收益或下单权限。
- **未完成 / 阻塞**：生产链路仍有缺口，不得通过伪造时间、来源、签名或放松门槛消除提示。

## 1. 市场与账户观察

- 连接用户自行登录的 TWS / IB Gateway，永久只读地读取账户、持仓、工作订单、合约及行情。
- 构建绑定账户、合约定义和同批逐腿报价的原子快照；保留来源、请求与交易所时间。
- 区分本地 API 连接、券商上游健康、账户快照新鲜度和可执行报价完整性。
- 支持已有持仓的逐腿展示、成本 / 券商估值 / 盈亏字段、组合到期损益和只读平仓观察。
- **边界**：缺少价格或盈亏时展示不可用；旧账户缓存不是当前持仓证明，估值不是成交价。

## 2. 新闻、事件和基本面

- 汇集可选 Finnhub、Alpha Vantage、Jin10 及公开官方来源；提供来源健康与配置状态。
- 保留新闻发布时间、首次获知时间、来源和分析版本，支持事件分类、实体映射与去重。
- 提供事件时间线、经济日历、每周简报、事件后市场反应和覆盖率说明。
- 从 SEC 等来源整理基本面证据并维护公司身份和时点一致性。
- **边界**：覆盖、授权和时效依赖来源；新闻、基本面解释和事件反应都是支持性证据，不直接授予交易资格。

## 3. 股票研究池与期权结构池

- 通过有界的券商发现漏斗和支持性证据组织股票研究池，记录筛选理由、缺失因素和排除原因。
- 组织合约明确的期权组合：逐腿方向、数量、到期、行权价、权利、报价、Greeks、流动性和有限损失。
- 提供研究分配、候选快照、联合排名，以及盘前研究和开盘重估的不同视图。
- 保留盘后指示性估值和下一交易日准备结果，与可执行交易证据分开。
- **边界**：最多十个研究候选不意味着存在十个可操作建议；无合格输入时允许空列表和 `NO_TRADE`。

## 4. 历史数据与分析特征

- 有界采集 IBKR 原生价格历史和历史隐含波动率，并保存请求、响应、来源及哈希链。
- 提供特征来源缓存、按候选绑定的诊断视图以及 EMA20、IV 百分位、QQQ → SPY 对标的计算约定。
- 包含波动率、情景收益、到期损益、流动性、成本和持仓定位等确定性分析。
- **边界**：历史片段数量不等于交易日覆盖或口径验证；特征预览不能替代生产特征入口。
  生产特征生成和真实 ATM 曲面 / 可比 IV 输入仍有明确阻塞。

## 5. 决策、排名与风险

- 固定顺序处理发现、数据绑定、组合生成、风险与成本门槛、排名和持久化决策。
- 以 `Decimal` 处理金额和概率，计算有限最大损失、策略 NAV 风险占比及费用后条件。
- 实施单一开放组合、正常 / A 级 / 硬上限、DTE 与时间退出约束；支持持仓管理专用路径。
- 对陈旧、冲突、不完整、不可验证或缺乏真实授权的输入关闭可操作资格。
- **边界**：已实现风险和排名算法不证明策略有正收益；个人 NAV 账本及授权不随源码发布。

## 6. AI 解释、影子研究和学习

- 可选 DeepSeek 仅接收窄白名单的去隐私输入，提供支持性解释和影子研究。
- 跟踪模型配置、用量成本、预测、观察结果、学习记录、回放、相似场景和覆盖进度。
- 区分 Champion / Challenger 与影子评估；缺乏独立结果时明确标注未知。
- **边界**：不得把账户、持仓、订单、指令或凭据发送给模型；模型输出不能改变生产权重、风险规则或权限。

## 7. 审批、桥接和安全

- 实现短时、哈希绑定、单次使用的 Rank 1 审批挑战及桥接状态机。
- 为将来的 IBKR 复核指令保留重新校验和单次外部尝试边界；不确定结果禁止自动重试。
- 提供授权验证、撤销、只读请求节流、Windows DPAPI 保护和敏感内容清理。
- **边界**：有审批 / 桥接代码不等于 creator transport 已签署或启用；actor 标签和自哈希不是人类签名。
  程序永久没有提交、修改、撤销真实订单的能力。

## 8. 本地 GUI、调度和维护

- FastAPI 在 `127.0.0.1:8891` 提供本地 API，原生 HTML / CSS / JavaScript 展示状态并定时刷新。
- 展示账户与来源健康、新闻和日历、研究池、持仓、诊断、学习证据和禁用原因。
- 有界日程覆盖盘前研究、冻结、重估、普通扫描、结果处理、盘后发现和下一交易日准备。
- PowerShell 启动器检查端口归属，使用项目专用环境；锁定依赖、完整性和权限审计脚本辅助维护。
- **边界**：日程需要有效日历和父任务租约，部分错过任务不会自动补跑；克隆、开端口和测试通过都不等于整流程验收。
